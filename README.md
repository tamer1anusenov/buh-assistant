# Налоговый помощник для ИП Казахстана

Загрузите TXT-выписку за полугодие 2026 — приложение рассчитает налог по
упрощённой декларации и покажет спорные операции. Расчёт выполняется локально,
API-ключ и LLM не нужны.

> Текущая версия показывает **предварительную оценку**. Правило Астаны имеет
> статус `draft` и ожидает проверки человеком. Расчёт относится к загруженной
> выписке; социальные платежи и корректировки по работникам пока не учитываются.

## Быстрый запуск

Понадобятся **Python 3.11+** и **uv**. Инструкция установки uv доступна
[в документации](https://docs.astral.sh/uv/getting-started/installation/).
Склонируйте репозиторий и перейдите в папку проекта.

```bash
git clone https://github.com/tamer1anusenov/buh-assistant.git
cd buh-assistant
uv sync --locked
uv run --locked python -m streamlit run accounting_assistant/frontend/app.py
```

Откройте **http://localhost:8501**. Для остановки нажмите **Ctrl+C** в терминале.
Для первого запуска `.env` не требуется; установка зависимостей требует интернета.

## Попробовать на примере

1. Сохраните профиль ИП — регион **Астана**, наличие работников по вашему примеру.
2. Выберите **1-е полугодие 2026**.
3. Загрузите файл [test_statement_ip_h1_2026.txt](tests/fixtures/statements/test_statement_ip_h1_2026.txt).
4. Результат появится автоматически. Решения можно исправлять в таблице.

Ожидаемый результат учебной выписки — **12 операций**, база **1 120 000 ₸**,
налог **33 600 ₸**, верхняя граница по KZT **36 000 ₸**. Операция на **1 000 USD**
показана отдельно и не входит в диапазон. Подтверждение этих сумм бухгалтером
остаётся условием релиза.

Уже уплаченный налог можно указать по желанию, в том числе `0`. Остаток к уплате
доступен только при подтверждённом правиле и определённой сумме налога.

## Формат выписки

Файл в кодировке **UTF-8**, одна операция на строку, поля разделены `|`.

```text
№ | Дата | Тип | Контрагент | Назначение | Сумма | Валюта
1 | 2026-01-15 | Поступление | Учебный клиент | Оплата услуг по акту №1 | 100000.00 | KZT
```

Дата задаётся как `YYYY-MM-DD`. Допускаются типы «Поступление» и «Списание».
Дубли, возвраты, займы и переводы между своими счетами исключаются по правилам
классификации. Неоднозначные операции увеличивают верхнюю границу. Если сумма
или валюта не распознана, верхняя граница может остаться неопределённой.
Иностранная валюта без курса отображается отдельно.

## Данные и история

Профиль сохраняется для следующих запусков. История расчётов доступна на экране.
Данные хранятся в `data/accounting.db`; путь можно изменить через
`ACCOUNTING_DATABASE_PATH` в `.env`.

Приложение предназначено для локального использования: профиль общий,
авторизации нет. В потоке v2 исходный файл не сохраняется, ИИН и стандартные
казахстанские IBAN маскируются перед записью. Старые записи прежнего приложения
могут содержать исходные документы.

## Командная строка и тесты

Расчёт учебного примера без браузера:

```bash
uv run --locked python -m accounting_assistant.statement_v2 tests/fixtures/statements/test_statement_ip_h1_2026.txt --half 1 --region Астана
```

Запуск тестов:

```bash
uv sync --locked --extra dev
uv run --locked --extra dev python -m pytest -q
```

[Правовые источники](rules/sources/manifest.json), [заметки для проверяющего](rules/REVIEW.md)
и [лист сверки бухгалтером](examples/v2_accountant_review.json) находятся в репозитории.
Команда допуска к релизу завершится ошибкой, пока правило и контрольный расчёт
не подтверждены человеком:

```bash
uv run --locked python -m accounting_assistant.release_check tests/fixtures/statements/test_statement_ip_h1_2026.txt examples/v2_accountant_review.json
```

Если порт занят, добавьте к команде Streamlit `--server.port=8502` и откройте
http://localhost:8502. Для ошибки доступа к кешу uv укажите доступный каталог
через переменную окружения `UV_CACHE_DIR`.

В репозитории также сохранён отдельный аудитор договоров.
[Его документация находится здесь](docs/lexaudit.md).
