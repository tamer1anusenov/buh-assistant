# Черновик правовой проверки

Регион примера — Астана. Все правила и значения имеют статус `draft`.
Проверяющий и дата его проверки не заполнены. Вступление в силу Кодекса
зафиксировано в статье 848, пункт 1. Дата 31.12.2026 в данных расчёта ограничивает
область этого MVP; она не означает прекращение действия нормативного акта.

| Вопрос | Норма из сохранённого текста |
|---|---|
| Налоговый период | Статья 722, пункт 3 — полугодие |
| Условия режима | Статья 723, пункты 1 и 2 |
| Лимит дохода | Статья 723, пункт 1, подпункт 1 — 600000 МРП за календарный год |
| Объект | Статья 724, пункт 1 — доход по методу начисления |
| Признание дохода от услуг | Статья 725, пункт 4 — акт или иной подтверждающий документ |
| Базовая ставка | Статья 726, часть 1 — 4% |
| Изменение маслихатом | Статья 726, часть 2 — увеличение или уменьшение не более чем на 50%; диапазон 2–6% является арифметическим следствием |
| Срок представления | Статья 727, пункт 1 — не позднее 15 числа второго месяца после периода |
| Срок уплаты | Статья 727, пункт 2 — не позднее 25 числа второго месяца после периода |
| МРП 2026 | Закон о республиканском бюджете, статья 7, подпункт 4 — 4325 тенге |
| Астана | Решение маслихата, пункт 1 — 3%, пункт 2 — с 01.01.2026 |
| Форма 910.00 | Приказ № 695, пункт 1, подпункт 27, приложение 27; пункт 3 о введении с 01.01.2026 |

Прямых расхождений с предложенными числами не найдено. Полугодовой доход
сам по себе не подтверждает годовой лимит. Банковский платёж сам по себе
не устанавливает дату признания дохода. В интерфейсе требуется подтверждение
по первичным документам, включая неоплаченный доход.

Снимки являются извлечённым текстом соответствующих статей из HTML Adilet.
Сохранены SHA-256 каждого UTF-8 снимка и исходного HTTP-ответа. Даты доступа
указаны с часовым поясом. Главная версия Adilet возвращала оболочку JavaScript;
тексты прочитаны с официального old.adilet.zan.kz.

До подтверждения человеком необходимо проверить применимость редакции к
конкретному полугодию, все ограничения статьи 723, запрещённые виды деятельности,
годовой доход, первичные документы, округление и действующее региональное
решение. Полнота формы 910.00, включая социальные обязательства, этим расчётом
не подтверждается. Проверка правил в коде не заменяет эту правовую проверку.
